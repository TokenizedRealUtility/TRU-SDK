# Changelog

## 1.0.0

Initial TRU developer SDK.

- Direct authenticated TRU Core JSON-RPC transport
- Public wallet/mining gateway support
- 106-method source-derived Core RPC catalog
- Chain, network, wallet, transaction, token, TRUScript, contract, Magic Lock, mining, AI, identity, HTLC and swap modules
- Explorer REST client
- NEROMESH / AXON HTTP client
- Block polling/event abstraction
- Exact TRU amount helpers (`bigint`)
- TRU mainnet address validation helper
- Structured SDK error classes
- Compatibility check
- TypeScript declarations
- Zero runtime npm dependencies
